**K-Means Clustering on Breast Cancer Dataset**
This notebook demonstrates unsupervised clustering using K-Means on the Breast Cancer dataset. Clustering is an exploratory technique that groups data points based on similarity without using labels, and K-Means is a popular algorithm that partitions data into K clusters by minimizing distances to cluster centroids.
We begin by loading and preprocessing the dataset, including feature scaling to ensure all features contribute equally. K-Means is then applied to identify clusters within the data. Since the dataset includes true labels (benign vs malignant tumors), we align the predicted clusters with these labels to evaluate performance. Metrics such as accuracy and misclassification rate provide quantitative insight into how well the clustering captures the underlying class structure.
To visualize the clusters, we use Principal Component Analysis (PCA) to reduce the data to two and three dimensions. The notebook includes both 2D scatter plots and a 3D animated visualization of the clusters, making it easier to see the separation between the groups and any overlaps. True labels are overlaid on the plots to allow a direct comparison between K-Means clusters and the actual tumor classifications.
This notebook highlights how K-Means can reveal patterns in high-dimensional data, even when the underlying structure is not explicitly provided. It also demonstrates practical steps for data preprocessing, cluster evaluation, and visualization, providing a complete workflow for unsupervised learning on real-world datasets.
